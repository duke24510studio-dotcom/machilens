# MACHILENS 会社紹介

## 一言紹介

MACHILENSは、自治体・商工会・地域企業のAI活用を、教材・研修・導入コンサルで支援する地域DXブランドです。

## ブランドステートメント

地域を見るための、新しいレンズをつくる。

地方の現場には、すでに知恵があります。人の関係性、地域の文脈、役場や商工会にしかわからない判断の積み重ねがあります。MACHILENSは、その知恵をAIで置き換えるのではなく、詰まっている業務を軽くし、現場の判断に使える時間を取り戻すために存在します。

## 提供価値

- 役所言葉に翻訳したAI活用
- 現場業務に直結するプロンプトと手順
- 上司、議会、関係者へ説明できるROI設計
- 教材から研修、導入コンサルまでの一貫支援
- 観光PR、広報、補助金、議事録に強い地域実装

## 主な対象

- 自治体職員
- 商工会、観光協会
- 地域中小企業
- 地域おこし協力隊
- 地域DXや観光DXを進めたい団体

## 事業メニュー

### 1. 教材販売

「まちレンズ式 自治体・地域企業のためのClaude実装教科書」をUdemyとnoteで展開します。教材は単体収益だけでなく、導入コンサルや研修の営業資産として機能させます。

### 2. 研修・講演

自治体職員、商工会員、地域企業向けに、Claudeを使った業務効率化研修を実施します。対象業務に合わせて、議事録、広報、補助金、観光PRなどへ絞り込みます。

### 3. 導入コンサル

1業務から小さく実装し、削減時間を数字で記録します。最初の成果をもとに、部長会、議会、関係者説明へ使える資料に落とし込みます。

### 4. コンテンツエンジン構築

地域向けAI運用の知見を応用し、X、note、YouTube、LINEを連動させる投稿生成フローを設計します。1日30分で承認と返信だけを行う運用を目指します。

## 営業時の短い説明

まちレンズは、自治体や商工会のためのAI実装支援です。ChatGPTやClaudeを紹介して終わりではなく、議事録、観光案内メール、補助金対応、広報原稿など、今ある業務にAIを入れて、削減時間を数字で説明できる状態まで伴走します。
