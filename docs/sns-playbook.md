# MACHILENS SNSプレイブック

## 基本方針

@machilensは、観光アカウントではなく「AI×地方自治体」の専門メディアとして育てます。特定地域名は出さず、小規模自治体・地域団体での実装知見として発信します。

## 3つの運用ルール

1. 1日30分しか使わない。投稿作成はAIで自動化し、人間は承認と返信に集中する。
2. 教材販売が最優先。すべての投稿は教材LP、note、LINE、Udemyへの導線として設計する。
3. 最初の100日間は、フォロワー数より検索で見つかる資産型コンテンツを積む。

## 投稿の3層構造

### Layer 1: 吸引コンテンツ

目的は認知拡大。XとThreadsで使います。

- 削減時間の数字
- Before/After
- 失敗談
- 自治体AI導入の誤解

### Layer 2: 教育コンテンツ

目的は信頼構築。note無料記事とYouTubeで使います。

- プロンプト例
- 具体的手順
- セキュリティの注意点
- Claudeと他ツールの比較

### Layer 3: 販売コンテンツ

目的は収益化。note有料記事、Udemy、LINEで使います。

- 教材ダイジェスト
- 特典紹介
- 受講者の声
- 早期特典、限定サポート

## プラットフォーム別運用

### X

- 頻度: 1日2から3投稿
- 役割: 認知拡大と検索流入
- 型: 数字、Before/After、プロンプト公開、質問回答
- CTA: note記事、教材LP、LINE登録

### note

- 頻度: 週2本
- 役割: SEOと教材テキスト版の販売基盤
- 型: 無料記事1本、有料記事1本
- CTA: Udemy教材、LINE登録、相談

### YouTube

- 頻度: 週1本
- 役割: 朝霧フィルムズの品質を見せ、教材への信頼を作る
- 型: 教材の一部切り出し、5から10分の解説
- CTA: 概要欄からUdemy教材

### LINE

- 頻度: 週1配信
- 役割: ローンチ前の濃い見込み客づくり
- 型: note要約、先行特典、相談受付
- CTA: 早期購入、個別相談
